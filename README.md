# AI Student Performance Prediction

## Project Overview

The Student Performance Prediction System is a machine learning-based application that predicts a student's academic performance using different academic and study-related factors.

## Features

- Predicts student academic performance
- Uses attendance and study-related information
- Provides real-time prediction
- Simple and user-friendly interface
- Helps analyze factors affecting student performance

## Input Features

- Attendance
- Study Hours
- Assignment Score
- Internal Marks
- Previous Exam Score

## Technologies Used

- Python
- Machine Learning
- HTML
- CSS
- JavaScript
- GitHub

## Objective

The main objective of this project is to use machine learning techniques to predict student performance based on academic and study-related factors.
